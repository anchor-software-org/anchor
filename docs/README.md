# Anchor documentation

This directory contains documentation for Anchor users, contributors, and maintainers.

## Public documentation

- `public/getting-started/installation.md`
- `public/getting-started/compatibility.md`
- `public/reference/feature-comparison.md`
- `public/tutorials/clipboard-sync.md`
- `public/tutorials/extend-display.md`
- `public/tutorials/phone-as-webcam.md`

The website publishes them under `/docs`

## Developer documentation

`developer/` contains repository and implementation guidance:

- `development-environment.md` — set up a local development environment.
- `architecture/` — current networking and Wayland capture architecture.
- `protocol/` — the current transport contract.

## Maintainer documentation

`maintainers/` contains operational docs for maintainers and those looking to work on Anchor. 

- `maintainers/performance/sideboat-production-baseline.md` — local encoder,
  framing, and VA-API baseline.

Feedback is routed to `devs@anchor-software.org`.

## Documentation rules

- Describe behavior that exists in the current code.
- Use concise, direct instructions.
- Test commands, links, and examples before publishing them.
- Mark previews and platform limitations clearly.
