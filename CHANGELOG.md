# Changelog

## 1.0.0 — 2026-09-26

First stable Anchor release.

- Align the Android and Linux desktop applications with Anchor SDK 1.0.0 and
  Anchor Protocol v1.
- Pair Android devices and Linux desktops directly using authenticated,
  certificate-pinned transport.
- Provide optional messaging, notification, clipboard, file-transfer, camera,
  media, display, and remote-input features.
