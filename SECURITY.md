# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email
[devs@anchor-software.org](mailto:devs@anchor-software.org) with a concise
description, affected revision or release, reproduction steps, and any
potential impact. Do not include private user data, credentials, certificates,
or private keys.

We will acknowledge reports, assess impact, and coordinate disclosure through that address. Until a release support policy is published, only the current `main` branch and the latest released Android and Linux builds receive fixes.

## Scope

The Android app, Linux desktop app, website/worker, Protocol v1 schemas, and SDKs are in scope. Third-party dependencies should normally be reported to their upstream maintainers as well.
