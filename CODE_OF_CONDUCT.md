# Contributor Covenant Code of Conduct

## Expected behavior

Use welcoming language, respect differing viewpoints, accept constructive
feedback, and focus on what is best.

## Unacceptable behavior

Don't be a jerk

## Enforcement

This policy is adapted from the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).
